# Gazon

**Gazon** — планируемое приложение для iPhone, которое поможет сотрудникам ПВЗ и склада оценивать время окончания разбора отправлений после разгрузки поставки.

**Статус:** исходный код и Xcode-проект добавлены. Готовность сборки проверяй в [Actions](https://github.com/folzy1092/gazon/actions). Это первая версия, её поведение будет уточняться по результатам тестирования.

## Как это будет работать

1. Вводишь время начала и общее число отправлений, например `0 / 553`.
2. По ходу работы добавляешь накопленный результат: `215`, потом `359`.
3. Gazon показывает остаток, темп и примерное время окончания с диапазоном.
4. При смене числа сотрудников отмечаешь событие, чтобы прогноз опирался на новые замеры.
5. После завершения смотришь длительность, график и историю.

Число грузовых мест можно указать отдельно как справку. Оно **не** входит в расчёт отправлений. Номер перевозки необязателен; интеграции с системой доставки нет.

## Планируемые возможности

- Быстрый ввод замера с автоматическим текущим временем.
- Прогноз по последним интервалам, возможность выбрать другой метод.
- Смена состава команды, исправление и удаление ошибочных замеров.
- История приёмок и график.
- Светлая, тёмная и системная темы, Dynamic Type.
- Локальное хранение через SwiftData, без аккаунтов, сервера и аналитики.

Точные правила расчёта, экраны и критерии готовности: [SPEC.md](SPEC.md).

## Разработка

Стек: Swift, SwiftUI, SwiftData, Apple Charts, iOS 17+. Открой `Gazon.xcodeproj` в Xcode, выбери схему `Gazon`. Workflow [iOS](.github/workflows/ios.yml) запускается при push в `main` и pull request: чистая сборка для симулятора, unit-тесты и сборка для физического устройства. После успеха в артефактах запуска появится `Gazon-unsigned-ipa`. Скачай ZIP артефакта и извлеки `Gazon-unsigned.ipa`. IPA **не подписан**, перед установкой на iPhone его нужно подписать собственным сертификатом через eSign или Xcode.

Данные будут оставаться на устройстве. Реальные персональные данные из примеров поставок в публичный репозиторий не добавляются.
